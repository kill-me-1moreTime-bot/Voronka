# Утренняя воронка

Страница с рецептами V60 для пяти зёрен Tasty Coffee: 1 или 2 кружки, температура, помол Timemore C5 ESP, график проливов, журнал заварок.

## Файлы
- `index.html` — вся страница (разметка, стили, скрипт в одном файле).
- `CLAUDE.md` — заметки для Claude Code.

## Открыть локально
Откройте `index.html` в браузере.

## Известное ограничение
Журнал заварок и правка рецептов были написаны под хранилище артефакта Claude (`claude.use("db")`).
Вне артефакта хранилища нет, поэтому кнопки записи отключены. Первая задача для Claude Code — заменить его на `localStorage` (с экспортом в файл).
