# Проект «Утренняя воронка»

- Один файл `index.html`, без сборки и библиотек. Шрифты с Google Fonts.
- Язык интерфейса: русский. Тексты короткие, без англицизмов.
- Пользователь смотрит страницу на телефоне (Android), поэтому: ширина 400 px, крупные поля, без закреплённых панелей и анимаций сдвига (они давали белые артефакты при появлении клавиатуры).
- Цвета только через переменные `:root`, светлая и тёмная темы.
- Оборудование: воронка Cafec V60, фильтры Abaca+, мельница Timemore Chestnut C5 ESP (не Pro, у Pro складная ручка): 10 цифр на оборот, между цифрами 5 щелчков (проверено на мельнице), щелчок 15 мкм (50 щелчков на оборот), чайник Kitfort.
- Помол записывается как «1 оборот + деление» (например, 8,5).
- Хранилище: `localStorage`, ключ `voronka-data` (`beanDocs` и `brews`), черновики формы в `voronka-drafts`. Есть скачивание и загрузка копии JSON.
- При первом запуске в память кладутся две заварки гейши от 29.09.
- Страница открывается как обычный сайт, не в iframe. В iframe приложения Claude на Android поля ввода отрисовывались белыми пятнами.

## Сделано
- Хранилище заменено на localStorage, добавлены экспорт и импорт.
- Кнопка «Разобрать заварки в Claude» открывает чат claude.ai с готовым текстом (рецепт, записи, вопросы) и копирует его.
- Запись заварки создаётся только кнопкой «Сохранить заварку» в конце формы, до этого пишется лишь черновик.

- Сайт опубликован на GitHub Pages. Установка на главный экран: `manifest.webmanifest`, иконки `icon-*.png`.
- Работа без сети: `sw.js` (сеть сначала, кэш при отсутствии сети). После изменения файлов поднимайте `CACHE` в `sw.js`.

- Коллекция зёрен: все зёрна лежат в `catalog` (поле `status`: `active` — на панели, `shelf` — в коллекции). Вкладки сверху показывают только `active`. Из коллекции можно добавить, изменить, вернуть на панель, удалить (только без записей заварок).
- Заполнение по фото без API: кнопка открывает `claude.ai/new?q=...` с просьбой вернуть JSON, ответ вставляется в форму. Схема JSON: name, country, process, score, roast (ГГГГ-ММ-ДД), notes[].
- Начальные температура и помол нового зерна берутся из `PROC` по обработке.

- Секундомер в форме заварки: «Старт» в начале блюма, дальше кнопка «Начал пролив N» записывает время, последняя кнопка «Слив закончился» записывает слив. Экран не гаснет (Wake Lock), у времён есть кнопки − и + по секунде.

- Оборудование: строка над заголовком (воронка · фильтры · мельница) открывает форму «Моё оборудование». Данные лежат в `equipment` и попадают в текст для разбора заварок.

- Блум: поле `bloom` в рецепте и заварке (`swirl` покрутить, `spoon` ложка, `none` не трогать; нет поля → `swirl`). Выбор на карточке, в редакторе и в форме заварки, попадает в текст для разбора.
- Вкладка «Гайды» (`GUIDES` в index.html): блум и подготовка фильтра, только проверенные ссылки на видео.

- Вместо крупного заголовка вверху две кнопки «Коллекция» и «Гайды» (`#mainNav`); заголовок h1 скрыт визуально. Вкладки зёрен крупнее.
- Стартовая заставка `#splash` (эмблема `icon-192.png`), показывается один раз за запуск (`sessionStorage`), гаснет через 1,4 с или по нажатию; только прозрачность, без сдвигов.

- В «Гайдах» первым идёт блок «Три способа заваривания» (`METHODS`): вкладки Хоффман / Касуя 4:6 / Осмотик, шаги пересчитаны на 15 г / 240 г, ссылки на ролик с временной меткой. Для Осмотика граммы не подтверждены, поэтому шагов нет.

- «Гайды» — раскрывающиеся списки (`<details class="guide">`, по умолчанию свёрнуты, без анимации). Ссылка «как выбрать» у блума открывает нужный гайд.

- Гайды сгруппированы (`GUIDE_GROUPS`): Основы, Как настроить, Техника, Вкус, Уход. Видео только проверенные по названию и каналу через oembed. Блок «Если чашка не та» на главной тоже спойлер (`#fixBox`), в гайдах скрыт.

## Идеи на потом
1. График слива по заваркам одного зерна.
2. Звуковой сигнал за 5 секунд до следующего пролива.
