# Проект «Утренняя воронка»

- Один файл `index.html`, без сборки и библиотек. Шрифты с Google Fonts.
- Язык интерфейса: русский. Тексты короткие, без англицизмов.
- Пользователь смотрит страницу на телефоне (Android), поэтому: ширина 400 px, крупные поля, без закреплённых панелей и анимаций сдвига (они давали белые артефакты при появлении клавиатуры).
- Цвета только через переменные `:root`, светлая и тёмная темы.
- Оборудование: воронка Cafec V60, фильтры Abaca+, мельница Timemore C5 ESP (50 щелчков на оборот, 15 мкм), чайник Kitfort.
- Помол записывается как «1 оборот + деление» (например, 8,5).
- Хранилище: `localStorage`, ключ `voronka-data` (`beanDocs` и `brews`), черновики формы в `voronka-drafts`. Есть скачивание и загрузка копии JSON.
- При первом запуске в память кладутся две заварки гейши от 29.09.
- Страница открывается как обычный сайт, не в iframe. В iframe приложения Claude на Android поля ввода отрисовывались белыми пятнами.

## Сделано
- Хранилище заменено на localStorage, добавлены экспорт и импорт.
- Кнопка «Разобрать заварки в Claude» открывает чат claude.ai с готовым текстом (рецепт, записи, вопросы) и копирует его.
- Запись заварки создаётся только кнопкой «Сохранить заварку» в конце формы, до этого пишется лишь черновик.

- Сайт опубликован на GitHub Pages. Установка на главный экран: `manifest.webmanifest`, иконки `icon-*.png`.
- Работа без сети: `sw.js` (сеть сначала, кэш при отсутствии сети). После изменения файлов поднимайте `CACHE` в `sw.js`.

- Коллекция зёрен: все зёрна лежат в `catalog` (поле `status`: `active` — на панели, `shelf` — в коллекции). Вкладки сверху показывают только `active`. Из коллекции можно добавить, изменить, вернуть на панель, удалить (только без записей заварок).
- Заполнение по фото без API: кнопка открывает `claude.ai/new?q=...` с просьбой вернуть JSON, ответ вставляется в форму. Схема JSON: name, country, process, score, roast (ГГГГ-ММ-ДД), notes[].
- Начальные температура и помол нового зерна берутся из `PROC` по обработке.
