# Сказочные друзья

Android-приложение для детей 3–5 лет. Персонаж на экране разговаривает с ребёнком голосом. В основе — Yandex AI Studio Realtime API: распознавание речи, диалог и синтез идут в одном канале.

Что уже есть:

- Три оригинальных персонажа: Мишка Топтыжка, Волчонок Вова, Зайка Зоя. Каждый начинает разговор со своей маленькой проблемы.
- Живая анимация без готовых файлов: моргание, «дыхание», рот открывается по громкости голоса, взгляд вверх, когда персонаж слушает.
- Голосовой диалог: персонаж говорит первым, потом слушает ребёнка.
- Два слоя безопасности: детский промпт и проверка текста каждого ответа до того, как ребёнок его услышит.
- Настройки для взрослых (открываются долгим нажатием 3 секунды): имя, возраст, длительность разговора. По таймеру персонаж сам прощается и предлагает порисовать.
- Пауза и стоп для взрослого. Касание персонажа во время речи — он замолкает и слушает.

Камера, мини-игры и Rive-анимация — следующие шаги, они расписаны задачами для Cursor в [docs/CURSOR_TASKS.md](docs/CURSOR_TASKS.md).

> Код написан без запуска: в среде, где он готовился, не было Flutter SDK. Первое, что нужно сделать, — собрать проект и прогнать задачу 0 из CURSOR_TASKS.md. Ошибки сборки Cursor исправит по сообщениям компилятора.

## Установка (один раз)

### 1. Инструменты

1. Установите **Flutter SDK** по инструкции для своей ОС на flutter.dev (если сайт не открывается — через VPN). Проверка: `flutter doctor`.
2. Установите **Android Studio** — оттуда нужен только Android SDK. В `flutter doctor` должна быть зелёная галочка у Android toolchain. Если просит — выполните `flutter doctor --android-licenses`.
3. Откройте папку проекта в **Cursor**.

### 2. Создайте Android-часть

> Папка `android/` уже создана и лежит в репозитории, этот шаг можно пропустить. Он нужен, только если папку удалили.

В терминале Cursor, в папке проекта:

```bash
flutter create --org ru.skazki --project-name skazochnye_druzya --platforms android .
dart tool/patch_android.dart
flutter pub get
```

`flutter create .` не перезаписывает уже существующие файлы — он только добавит папку `android/`. Скрипт `patch_android.dart` (запускать из корня проекта) впишет разрешения на интернет и микрофон и поднимет minSdk минимум до 23.

### 3. Yandex Cloud: каталог, ключ, оплата

Приложению нужны только **идентификатор каталога** и **API-ключ**. Промпт, голос и настройки сессии приложение отправляет само (`lib/prompts.dart`, `lib/characters.dart`), поэтому агента в AI Studio сохранять не обязательно.

1. Войдите в [Yandex AI Studio](https://aistudio.yandex.ru) с Яндекс ID. Создайте облако и каталог, если их ещё нет, и привяжите платёжный аккаунт: без него модели не отвечают.
2. **Идентификатор каталога** — строка вида `b1g…`. Её видно в адресе и в списке каталогов на странице AI Studio или в консоли Yandex Cloud.
3. **API-ключ.** В AI Studio кнопка создания API-ключа справа вверху. Ключ, созданный там, уже имеет нужную область `yc.ai.foundationModels.execute`. Если создаёте ключ в консоли Yandex Cloud: сервисный аккаунт с ролью `ai.models.user`, ключ с этой областью. Ключ показывается один раз, сохраните его.
4. По желанию: в AI Studio «Создать голосового агента», вставьте текст из `lib/prompts.dart` и поговорите голосом. Так можно послушать голоса и подобрать их персонажам.

Приложение подключается так же, как [официальный пример Yandex](https://github.com/yandex-ai-studio/yandex-ai-studio-api-examples/blob/main/realtime/voice_agent.py): `wss://ai.api.cloud.yandex.net/v1/realtime?model=gpt://<каталог>/speech-realtime-max-tts-live/latest`, заголовок `Authorization: Api-Key <ключ>`, звук PCM 44100 Гц.

Модель `speech-realtime-250923` из примера на GitHub больше не открывается (ошибка `model_access_denied`). Список моделей Realtime API есть в документации AI Studio. В настройках родителя есть выбор модели. «Живые голоса» (по умолчанию) — `speech-realtime-max-tts-live/latest`, голоса LiveTTS (`sofia`, `vera`, `vasily`, `sergey`, `denis`, `irina`, поле `liveVoice` в `lib/characters.dart`). «Прежняя» — `speech-realtime-deepseek-v4-flash`, голоса `ermil`, `filipp`, `jane` (поле `voice`).

Событие `input_audio_buffer.clear` Yandex сейчас не поддерживает и закрывает связь с ошибкой `malformed_event`, поэтому приложение его не отправляет.

### 4. Настройки подключения

**Проще всего — на телефоне.** Поставьте APK с GitHub (раздел «Сборка без компьютера» ниже), нажмите значок настроек (вход по отпечатку пальца или PIN телефона; если блокировка экрана не настроена — удерживайте значок 3 секунды) и в разделе «Подключение» вставьте идентификатор каталога и API-ключ. Адрес соберётся сам. В «Дополнительно» можно задать адрес вручную (например, если Yandex сменит модель) и схему авторизации. Всё хранится только на этом телефоне и не попадает в резервную копию Google.

**Или при сборке на своём компьютере**, через config.json. Значения с телефона важнее значений из config.json. Скопируйте `config.example.json` в `config.json` и заполните:

| Поле | Что вписать |
| --- | --- |
| `FOLDER_ID` | идентификатор каталога `b1g…` |
| `YANDEX_API_KEY` | API-ключ |
| `REALTIME_URL` | пусто — адрес соберётся из каталога |
| `AUTH_SCHEME` | `Api-Key` |
| `SAMPLE_RATE` | `44100`, как в примере Yandex |

`config.json` уже в `.gitignore` — в репозиторий он не попадёт.

Имена голосов персонажей заданы в `lib/characters.dart` (`ermil`, `filipp`, `jane`). Сверьте их со списком в плейграунде и замените при необходимости.

### 5. Запуск на телефоне

1. На телефоне: «Настройки → О телефоне» → 7 раз нажать на «Номер сборки» → появится «Для разработчиков» → включить «Отладка по USB».
2. Подключите телефон по USB, разрешите отладку.
3. В терминале:

```bash
flutter run --dart-define-from-file=config.json
```

В консоли будут строки `[RT] …` — это события сервера. По ним видно, что сессия настроилась и приходят ответы.

### 6. APK для установки без компьютера

```bash
flutter build apk --release --dart-define-from-file=config.json
```

Файл: `build/app/outputs/flutter-apk/app-release.apk`. Скопируйте на телефон и установите (разрешите «установку из неизвестных источников»).

> **Важно.** API-ключ попадает внутрь APK. Для своего телефона это нормально, но APK никому не передавайте. Перед тем как давать приложение другим, ключ нужно убрать на свой сервер — это отдельная задача в CURSOR_TASKS.md.

## Сборка без компьютера: GitHub Actions

Проект лежит в папке `skazochnye_druzya/` репозитория `Voronka`. После каждого коммита в эту папку GitHub сам проверяет код (`flutter analyze`), прогоняет тесты и собирает APK. Сценарий: `.github/workflows/skazki.yml` в корне репозитория.

1. **Actions → Сказочные друзья** → последний зелёный запуск (или **Run workflow**).
2. Внизу страницы запуска в разделе **Artifacts** скачайте `skazochnye-druzya-apk`. Это zip, внутри `app-debug.apk`. Откройте его на телефоне и установите.

Репозиторий публичный, поэтому **ключ Yandex в эту сборку не попадает**: APK со страницы запуска может скачать любой, у кого есть аккаунт GitHub. Адрес и ключ вводятся на телефоне в настройках для родителей, раздел «Подключение» (шаг 4).

## Журнал подключения на телефоне

На экране разговора справа вверху есть значок журнала. Удерживайте его 3 секунды. Откроется список событий сервера (`[RT] …`), ошибок и срабатываний фильтра, кнопка «Копировать» отправит его в буфер обмена. Так можно разобраться с подключением без USB. Время в журнале московское (часы:минуты:секунды), первая строка — дата. Журнал хранится только в памяти, последние 200 строк.

## Как устроено

```
Микрофон ──PCM16──▶ Realtime API (распознавание + LLM + синтез)
                         │
                         ▼
             ответ: аудио + текст
                         │
                 фильтр безопасности ──✗──▶ удалить из контекста,
                         │ ✓                 попросить другой ответ
                         ▼
          проигрывание + рот по громкости ──▶ снова слушаем
```

- **Полудуплекс.** Пока персонаж говорит, микрофон молчит: так он не слышит сам себя из динамика. Пока думает — микрофон открыт: если малыш договаривает после паузы, ответ на полфразы выбрасывается и сервер отвечает на всю фразу.
- **Ответ собирается целиком**, потом проверяется и только потом звучит. Ответ без текста считается непроверенным и не играет. Это добавляет полсекунды-секунду задержки, зато ребёнок не услышит то, что не прошло фильтр.
- **Ничего не сохраняется.** Журнал реплик живёт только в памяти, пока открыт экран разговора.

| Файл | Что внутри |
| --- | --- |
| `lib/prompts.dart` | детский системный промпт, приветствие, прощание |
| `lib/characters.dart` | персонажи: характер, история, голос, цвет |
| `lib/safety/safety_filter.dart` | список опасных тем и лимит длины ответа |
| `lib/session/conversation_controller.dart` | логика разговора и состояния |
| `lib/realtime/realtime_client.dart` | WebSocket и разбор событий сервера |
| `lib/audio/` | микрофон и проигрывание |
| `lib/ui/` | экраны и нарисованный персонаж |

## Перед первым показом ребёнку

1. `flutter test` — проверка фильтра безопасности.
2. Прогоните вручную фразы из [docs/SAFETY_TESTS.md](docs/SAFETY_TESTS.md), сами, голосом. Включая длинный разговор на 15 минут.
3. Первые разговоры — вместе, рядом с ребёнком.
