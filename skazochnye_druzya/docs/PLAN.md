## Где мы сейчас

- Шесть персонажей, свой мир и друзья, память о ребёнке, сцены на экране (счёт, прятки, загадка, картина дома), звонок другу через отдельное соединение, экран не гаснет, вход по отпечатку, счётчик расхода.

## 2. Надёжность

- **Секрет `SKAZKI_KEYSTORE_BASE64` на GitHub** (делает владелец) — без него APK из Actions не ставятся поверх.
- **Переподключение** при коротком обрыве связи: 1–2 попытки, персонаж продолжает с того же места.
- **Проверить звонок другу на телефоне** — переделан на отдельное соединение, на живом сервере не проверен.
- **Flutter 3.50+**: `package:flutter/material.dart` объявлен устаревшим, замена — `package:material_ui`. Перейти до обновления версии в сборке.
- **GitHub Actions**: `setup-java@v5`, `checkout@v5` (v4 устарели, Node 20).
- **Разделить `conversation_controller.dart`** (810 строк): звонок, сцены, расход — отдельными частями. Меньше шансов сломать одно, чиня другое.

## 3. Разговор

- **Распознавание детской речи**: попробовать без `noiseSuppress` / `autoGain`, сравнить строки `[Ребёнок]`; если не лучше — вернуть.
- **Эмодзи в ответах** (🐻): вырезать из текста до фильтра и журнала; промпт их уже запрещает.
- **Выбор голоса** у каждого персонажа в настройках с кнопкой «Послушать».
- **Профили детей** (задача 10) — если детей несколько.
