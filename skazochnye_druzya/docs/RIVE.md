# Анимация персонажа в Rive

Rive — редактор анимации (rive.app, работает в браузере и как приложение для компьютера). В нём рисуют персонажа из частей, «оживляют» его и задают правила: когда рот открыт, когда моргает, когда смотрит вверх. Результат — один файл `.riv`, который приложение проигрывает и которым управляет.

Чем это лучше картинок (`docs/ART.md`): плавные движения вместо смены кадров — рот открывается мягко по громкости, глаза моргают, уши шевелятся, хвост виляет, персонаж переходит из «слушает» в «думает» без скачков.

**Что нужно:** компьютер с браузером, мышь, несколько вечеров на первого персонажа. С телефона Rive неудобен. Экспорт `.riv` в приложение — на платном тарифе (около 9 $ в месяц по данным на конец 2026 года; проверьте на rive.app/pricing). Учиться и рисовать можно бесплатно, а файл, однажды выгруженный, работает навсегда — подписку можно отменить.

## План для одного персонажа

### 1. Части, а не одна картинка
Rive оживляет то, что нарисовано отдельными слоями. Нужно:

- тело, голова, два уха, хвост;
- глаза отдельно: белок, зрачок, блик, верхнее веко (для моргания);
- рот отдельно: закрытый, приоткрытый, широко открытый (или один рот, который тянется вниз);
- щёчки, брови (для «думает»).

Нарисовать можно прямо в Rive (векторные фигуры) или взять картинку из Gemini и разрезать её на слои в любом редакторе (Photopea в браузере бесплатна), сохранив каждую часть отдельным PNG с прозрачным фоном.

### 2. Кости (по желанию)
Голове, ушам и хвосту можно дать кости — тогда их удобно наклонять и покачивать. Для первого персонажа можно обойтись без костей: двигать и поворачивать сами слои.

### 3. Анимации (таймлайны)
В Rive каждая анимация — отдельная дорожка во времени:

| Название | Что делает | Длина |
| --- | --- | --- |
| `idle` | дыхание: тело чуть поднимается и опускается, хвост покачивается | 2–3 с, по кругу |
| `blink` | веки закрываются и открываются | 0,2 с |
| `mouth` | рот от закрытого (кадр 0) до широко открытого (последний кадр) | 1 с, без повтора |
| `listen` | уши торчком, взгляд чуть вверх | 0,3 с |
| `think` | взгляд в сторону, бровь вверх | 0,4 с |
| `happy` | подпрыгнул, улыбнулся | 0,6 с |

### 4. Машина состояний и управление
Машина состояний (State Machine) решает, какие анимации играют одновременно. Назовите её `Main`.

Управлять из приложения Rive сейчас советует через **Data Binding** (модель данных, View Model). Создайте View Model `Character` со свойствами:

| Свойство | Тип | Что значит |
| --- | --- | --- |
| `mouth` | число 0–100 | насколько открыт рот (приложение шлёт громкость речи) |
| `listening` | да/нет | персонаж слушает |
| `thinking` | да/нет | персонаж думает |
| `happy` | триггер | порадоваться (похвала, угадал зверя) |

В машине состояний:

- слой «база»: всегда играет `idle`, а `blink` — сам по себе раз в несколько секунд;
- слой «рот»: анимация `mouth` с «прокруткой» по свойству `mouth` (Blend State: 0 — закрыт, 100 — открыт);
- слой «настроение»: переходы в `listen`, если `listening` = да, в `think`, если `thinking` = да, обратно — когда нет;
- `happy` — разовый переход в `happy` и назад.

Старый способ — «Inputs» машины состояний с теми же именами (`mouth`, `listening`, `thinking`, `happy`) — тоже работает, но Rive помечает его устаревшим. Если по урокам удобнее Inputs — делайте Inputs, приложение подстроим.

### 5. Проверка в редакторе
В режиме проигрывания машины состояний (кнопка Play у State Machine) двигайте `mouth` и щёлкайте `listening`, `thinking`, `happy` — должно работать без приложения.

### 6. Выгрузка
Export → для runtime → файл `wolf.riv`. Пришлите его сюда. Я положу его в `assets/characters/wolf/wolf.riv` и подключу (задача 1 в `docs/CURSOR_TASKS.md`). Персонажи без `.riv` останутся на картинках или нарисованными кодом.

## С чего начать

1. Rive → Learn: короткие уроки по интерфейсу, анимации, машине состояний и Data Binding.
2. Rive Community / Marketplace: есть готовые говорящие персонажи с открытым ртом по числу — их можно открыть и посмотреть, как устроены (на чужом персонаже в своём приложении — только если автор разрешил, это указано в карточке).
3. Начните с одного персонажа и с малого: `idle` + `blink` + `mouth`. «Слушает», «думает», «радуется» — потом.
